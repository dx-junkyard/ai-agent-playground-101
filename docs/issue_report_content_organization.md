# Issue: 報告内容整理機能の実装（青梅市向けPoC）

## 概要

LINE通報AI管理システムにおいて、通報内容をAIが効率的に整理・ヒアリングする機能を実装します。
本Issueは青梅市のデータセットを使用したPoC（Proof of Concept）として、特に**獣害通報を中心**に実装します。

## 背景

現在のシステムでは、通報内容の整理が手動で行われており、効率化が課題となっています。
AIエージェントによる対話的なヒアリングにより、必要な情報を自動的に収集・整理する機能が必要です。

参考: [LINE通報AI管理システム](https://airs-jet.vercel.app/analysis)

## 実装要件

### 優先度: 高

#### 1. 報告内容整理機能（AIヒアリング）

- **目的**: 通報内容ごとに必要な項目をAIが対話形式でヒアリングする
- **対象**: 青梅市のデータセット（獣害中心、他数種類）
- **機能**:
  - 通報カテゴリの自動分類
  - 不足情報の検出と質問生成
  - 対話的な情報収集（複数ターン対応）
  - 収集した情報の構造化

#### 2. 拡張可能な構造

- 報告先振り分け機能は後から追加可能な設計
- カテゴリ定義とスロット定義を設定ファイル化
- 自治体別の設定を切り替え可能に

### 優先度: 低（今回は実装しない）

#### 報告先振り分け機能

- 国、都道府県、区市町村などの自治体別階層分け
- 担当課・担当省庁別の振り分け
- 今回は優先度低いため、後回し

## 技術設計

### アーキテクチャ

```
┌─────────────────┐
│  LINE通報受信   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ カテゴリ分類     │ (classify)
│ (獣害/その他)    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 情報抽出         │ (extract)
│ (場所/時間/種等) │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 不足情報検出     │ (validate)
└────────┬────────┘
         │
         ├─ 不足あり → ask_missing (AIヒアリング)
         │              │
         │              └─ ユーザー回答 → extract (再抽出)
         │
         └─ 不足なし → finalize (情報整理完了)
```

### データ構造

#### カテゴリ定義（獣害中心）

```python
CATEGORIES = [
    {
        "key": "wildlife_damage",
        "name": "獣害",
        "required_slots": [
            "location",      # 場所（GPS座標または住所）
            "time",          # 発見日時
            "species",       # 動物種（イノシシ/サル/カラス等）
            "details",       # 詳細状況
            "damage_type",   # 被害種別（農作物/人身/その他）
            "urgency"        # 緊急度
        ],
        "optional_slots": [
            "photo_url",     # 写真URL
            "witness_info",  # 目撃者情報
            "contact_info"  # 連絡先
        ]
    },
    # その他のカテゴリも同様に定義可能
]
```

#### スロット定義

```python
SLOT_DEFINITIONS = {
    "location": {
        "type": "location",
        "question": "場所を教えてください（住所またはGPS座標）",
        "validation": "location_validator",
        "extraction": "location_extractor"
    },
    "time": {
        "type": "datetime",
        "question": "いつ発見しましたか？（例：2026年1月20日 14時30分）",
        "validation": "datetime_validator",
        "extraction": "datetime_extractor"
    },
    "species": {
        "type": "enum",
        "question": "どんな動物ですか？（イノシシ/サル/カラス/その他）",
        "options": ["イノシシ", "サル", "カラス", "シカ", "その他"],
        "validation": "enum_validator",
        "extraction": "species_extractor"
    },
    # ... 他のスロット定義
}
```

## テストケース

### ケース1: 獣害通報（基本）

**入力**: "イノシシが畑を荒らしています"

**期待される対話**:
1. AI: "場所を教えてください"
2. ユーザー: "青梅市勝沼123"
3. AI: "いつ発見しましたか？"
4. ユーザー: "今日の朝"
5. AI: "被害の詳細を教えてください"
6. ユーザー: "トウモロコシが食べられました"
7. AI: "情報を確認しました。担当部署に連絡します。"

**期待される出力**:
```json
{
  "category": "wildlife_damage",
  "extracted": {
    "location": "青梅市勝沼123",
    "time": "2026-01-20 08:00",
    "species": "イノシシ",
    "details": "トウモロコシが食べられた",
    "damage_type": "農作物"
  },
  "is_complete": true
}
```

### ケース2: 情報不足の段階的ヒアリング

**入力**: "動物がいます"

**期待される対話**:
1. AI: "どんな動物ですか？"
2. ユーザー: "イノシシ"
3. AI: "場所を教えてください"
4. ユーザー: "青梅市"
5. AI: "もう少し詳しい場所を教えてください（住所またはGPS座標）"
...
