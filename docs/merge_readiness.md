## 他機能との連携

- **`/api/v1/user-message`**  
  - 福岡市向け LangGraph（`WorkflowManager`）。DB にメッセージ保存あり。  
  - 青梅市エンドポイントとは別ルート・別ワークフローで、相互に影響しません。
- **`/api/v1/user-messages`**  
  - ユーザー別会話履歴取得。青梅市エンドポイントは DB に保存しないため未使用。
- **DB**  
  - 青梅市は現状 DB 不要（PoC）。必要なら後から `user_id` とレスポンスの保存を追加可能。
- **AIClient**  
  - 青梅市ワークフローは `ReportOrganizer` のキーワード/ルールベースが中心。API キー未設定時はモックで起動可能。

## 既知の制限・前提

1. **マルチターン**  
   - 同一セッションで「カテゴリ・抽出結果」を引き継ぐ場合は、クライアントが前回レスポンスの `extracted` / `category` を `context` に含めて送る必要があります。  
   - エミュレーターは `lastContext` で前回レスポンスを保持し、次回送信時に `context` を付与するようにしています。
2. **会話履歴**  
   - `conversation_history` は現状「将来の感情分析・要約」用に受け取りのみ。分類・抽出には `context.extracted` / `context.category` を使用します。
3. **青梅市エンドポイントはメッセージを DB に保存しない**  
   - 履歴はクライアント側（または別ストア）で保持する想定です。
